SIGNAL HUB — CONTENT, SOURCING, IMAGE & EVIDENCE ENGINE

The visual redesign is now substantially complete.

DO NOT redesign the UI again.

The current problem is CONTENT.

The site currently contains only a handful of short placeholder articles, many with:

- 2–3 paragraphs
- NO RELEVANT ARCHIVE PHOTOGRAPH AVAILABLE
- 0 SOURCES
- 0 EVENTS
- UNVERIFIED
- SOURCE LINK UNAVAILABLE

This makes the beautifully designed website feel empty and unfinished.

The next phase is to build a real editorial/content/evidence pipeline.

The objective is to turn Signal Hub from:

"beautiful empty publication"

into:

"a continuously growing Indian public-interest evidence archive."

4. PRIMARY-SOURCE-FIRST RULE
==================================================

When an article discusses a government policy:

FIRST look for the original government document.

When discussing a court decision:

FIRST look for the actual judgment/order.

When discussing a UGC regulation:

FIRST look for the UGC notification/regulation.

When discussing constitutional provisions:

FIRST use India Code / official constitutional text.

Secondary news reports should supplement the primary source, not replace it when the primary source is available.

14. IMAGE STRATEGY
==================================================

NO RELEVANT ARCHIVE PHOTOGRAPH AVAILABLE

That should become uncommon once the content pipeline is operational.

Build a dedicated IMAGE DISCOVERY system.

Possible image sources:

1. Wikimedia Commons

2. Government/public-domain photographs where permitted

3. Official institutional media assets where reuse rights permit

4. Licensed stock provider

5. Original Signal Hub graphics
